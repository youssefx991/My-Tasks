Create WebAssembly Blazor App, which manages Trainees and their Tracks:
	- Create All CRUD operations to manage your application
	- try different routing for component pages
	- Use as much Razor Component as you can
	- Apply DataAnnotations on your classes
	- Use validation and visualize errors 

Track should have the following properties:
- ID
- Name
- Description

Trainee should have the following properties:
- ID
- Name
- Gender
- Email
- MobileNo
- Birthdate
- IsGraduated
